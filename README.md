# نهِ غیرممکن

پلتفرم سبک برای ساخت لینک‌های تعاملی فارسی — دکمهٔ «نه» فرار می‌کند، «بله» جشن می‌گیرد.

بدون دیتابیس. بدون ذخیره‌سازی.

## اجرا

```bash
npm install
npm run dev
```

## ساخت لینک

1. تم را انتخاب کنید (عاشقانه، شوخی، تولد، خواستگاری، سورپرایز)
2. فرم را پر کنید
3. «ساخت لینک» را بزنید

## فرمت URL

```
/v?d=ENCODED_PAYLOAD
```

Payload (JSON فشرده + base64url):

```json
{ "q": "سوال", "y": "بله", "n": "نه", "s": "پیام موفقیت", "t": "a", "r": 123456 }
```

- `t` — تم: `a` عاشقانه، `f` شوخی، `b` تولد، `p` خواستگاری، `s` سورپرایز
- `r` — seed تصادفی برای ترتیب پیام‌های فراری

## Deploy

Push به GitHub → Vercel خودکار deploy می‌کند.
